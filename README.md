## What I build

### Arcana — a programming language in Rust

**Rust · Cargo · CLI · Interpreter design**

Arcana is a fantasy-themed, general-purpose language with a tree-walking interpreter written in Rust. It is built to be strict, readable and friendly when something goes wrong.

The project covers:

- lexer, parser and interpreter;
- clear diagnostics with error codes, source snippets and "did you mean" hints;
- arbitrary-precision integers and a strict type model with no implicit truthiness;
- a standard library of ten modules (math, text, list, file, date and more);
- a command-line tool (`arcana run`, `arcana check`), a full test suite and complete documentation.
